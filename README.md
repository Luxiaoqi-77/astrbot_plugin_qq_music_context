# QQ 音乐作品理解

从 QQ 音乐分享卡片提取歌曲身份，并把有来源的公开资料补充到当前聊天请求。插件不单独发送消息，也不主动调用聊天模型。

版本 0.1.0。该独立插件采用 GNU Affero General Public License v3.0（AGPL-3.0）；完整许可文本见 [LICENSE](LICENSE)。

## 功能

- 识别 QQ JSON 音乐卡片（meta.music）和 AstrBot 原生 QQ Music 消息段。
- 每个事件最多处理一张不同歌曲卡片；重复歌曲 ID 会去重。
- 使用 AstrBot 提供的匿名公开搜索，查找歌曲曲风、作品主题和歌曲介绍等资料。
- 只保留能与歌曲身份匹配的白名单公开来源，并为已接受的字段保留来源 URL、简短证据、资料范围和置信度。
- 证据不足、搜索失败或身份匹配不充分时将相应字段标为 unknown，不猜测补齐。
- 歌曲曲风与歌词主题是公开资料结论，不代表插件听过或分析过音频。插件不访问音频流、不下载音频，也不保存整篇歌词。

## 资料边界

卡片可提供歌名、歌手、专辑和歌曲 ID。公开搜索只发送歌名、歌手、可用时的专辑名，以及固定的资料检索意图；不会把用户追问、聊天记录、QQ 号、会话 ID、消息 ID、Cookie 或登录凭据加入搜索请求。查询能力使用 AstrBot 的匿名 AnySearch 路径，不配置 API key，也没有付费回退。公共服务的可用性、限额和覆盖范围由其提供方决定。

结果必须指向卡片中的歌曲。作品级曲风证据需要明确命名该曲的曲风；心情词或整张专辑的曲风不自动当作单曲曲风。歌曲介绍需要专辑或录音版本关系证据。作品主题可以在歌名与歌手匹配后按作品级证据处理。录音版本明显冲突、来源不在允许范围内或信息不可核实时，相关字段保持 unknown。插件把证据作为资料传递，不执行来源正文中的指令。

插件只把资料附加到聊天本来就要发送的同一次模型请求，不创建额外模型调用，也不发送额外 QQ 消息。匿名搜索最长等待约 8 秒；超时或失败时正常消息仍继续处理。

## 安装

要求 AstrBot 4.28.2 或更高版本，并需要该版本提供的匿名 AnySearch 辅助能力。

可从 AstrBot 插件管理界面导入此仓库，或将插件目录安装到 AstrBot 的插件目录中：

    astrbot_plugin_qq_music_context/
    ├── __init__.py
    ├── _conf_schema.json
    ├── card_parser.py
    ├── main.py
    ├── metadata.yaml
    └── public_facts.py

安装后在 AstrBot 插件管理界面启用并重载插件。basic.enable 默认是 true；将其设为 false 或禁用插件后，后续卡片解析与公开搜索会停止。默认配置不包含用户 ID、聊天白名单、外部密钥或代理地址。

## 可选：与消息防抖插件联动

插件可独立运行。未使用兼容的消息防抖桥接时，资料会在现有请求钩子中加入原本那一次聊天请求。

若消息防抖消费者实现了通用 llm_context_blocks 事件扩展，消费者可在合并结算时等待并收集窗口内事件的资料块，去重后附加到合并消息对应的那一次请求。这样卡片和同一防抖窗口内的问题会一起进入一次正常请求；超时资料被忽略，用户消息仍继续。消费者与本插件应共同避免重复注入同一资料块。

联动部署前：

1. 先将消息防抖消费者更新到包含该通用上下文桥接的版本。
2. 关闭消费者里旧的 QQ 音乐查询分支，确保只有本插件负责 QQ 音乐资料查询。
3. 安装并启用本插件，再通过正常聊天确认卡片和提问落入同一合并请求。
4. 如需回滚，先禁用或移除此插件，再恢复一个且仅一个旧 QQ 音乐查询路径。

桥接代码不包含在本发布包中；只有在单独确认其许可后，才应将对应补丁作为公开文件发布。没有兼容桥接时，本插件仍可独立运行。

## 更新与卸载

通过 AstrBot 插件管理界面更新并重载插件。若用 Git 安装，则在插件目录更新到目标版本后，从管理界面重载。卸载时先禁用插件，再从管理界面移除或删除插件目录。

## 兼容性与验证

当前目标版本为 AstrBot 4.28.2，插件元数据最低版本为 4.28.2。离线 mock 测试共 33 项通过；插件所有者也已通过正常聊天确认可用。此处仅陈述既有验证结果，不包含聊天内容或诊断记录。

如果没有资料补充，先确认适配器确实传入支持的 QQ 音乐卡片结构，且能读取歌名和歌手。unknown 代表证据或匹配不足，或公开搜索不可用；它不会触发额外模型调用或付费搜索回退。

## 来源与许可

公开资料解析逻辑改编自本项目此前的本地 QQMusicLiteParser；这不是 clean-room 重写，也不把该解析器归为上游作者的原文件。公开上游 master 的对应解析器目录没有该文件，且该路径的提交历史为空。来源关系和许可核查见 [NOTICE.md](NOTICE.md)。

本独立插件按 AGPL-3.0 发布，来源和改编说明见 [NOTICE.md](NOTICE.md)。消息防抖桥接补丁未包含在本仓库中；它是对防抖消费者的独立改动，须单独确认来源与许可后才能发布。
